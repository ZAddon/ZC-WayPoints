**ZC WayPoints**

Cocok untuk anda yang suka bermain di server, dan suka membuat jebakan-jebakan, dan kalian kesulitan untuk mengingat di sebelah mana jebakan anda, dan di mana tempat untuk mengaktifkan jebakannya.

Jika benar seperti itu, maka **ZC WayPoints** adalah yang anda cari, karena ini tidak memerlukan **Behavior Packs** hanya membutuhkan **Resource Packs**, jadi anda dapat menggunakan **WayPoints** di **Server** manapun dan kapanpun
